    SpectraGQL Gateway Help & Overview

    🚀 What is SpectraGQL?
    SpectraGQL is an ultra-high-performance wire-speed API gateway and event-driven appliance built on Cloudflare's Pingora engine in Rust.
    🔀 Mode A (Sync Proxy / Reads)
    Reverse-proxies GraphQL queries and REST reads to upstream monoliths or microservices with connection pooling, retries, and passive telemetry logging.
    ⚡ Mode B (Async Edge / Writes)
    Terminates GraphQL mutations at the gateway edge: generates monotonic UUIDv7 Command IDs + HLC timestamps, dispatches raw payloads into append-only event sinks, and returns HTTP 200 ACCEPTED in <1ms.
    🏎️ Hot-Path Invariants (Zero Bloat)
    • Zero Redundant Deserialization: Reuses initial protocol decoded representation.
    • Zero Formatting on Hot Path: Unindented JSON only; pretty-printing shifted out-of-band to browser.
    • Lock-Free Atomics: Real client traffic never blocks on telemetry or observability locks.
    • Fail-Safe Propagation: Strict typed error handling with zero edge panics.
    📡 Supported Event Sinks
    First-class tier-1 support for NATS JetStream, Redis Streams (Valkey), Apache Kafka / Redpanda, Apache Iggy, and SierraDB.
    👷 BYOW Worker Discovery
    Zero worker code required: downstream workers in Go, Node, Python, or Rust are discovered natively via consumer group lag and partition telemetry.
